# 03 — Character Creation v0.1

> Builds on `02-core-rules.md`. Expand after Floor 1 playtest if needed.

## Floor 1 (tutorial intake)

1. **Name + look** (one line each)
2. Assign stats: **+3, +2, +1, +0, −1** to Strike, Grit, Wits, Sneak, Presence
3. **HP** = `10 + Grit` (min 6)
4. **Armor** = 0
5. **Credits** = 50
6. **Gear:** choose one junk melee (1d6), one personal trinket (0 slots if tiny), empty pack
7. **Hook:** one sentence — why this crawler is still funny/dangerous

No race/class yet.

## Floor 3+ (Continuum identity)

When the rural Continuum unlocks identity:

1. Pick a **Race** (table TBD — themed options; more unlock later)
2. Pick a **Class/path** (2 tagged abilities; weapon proficiency)
3. Keep prior stats; optional one free reassign of the −1 and a +0 if the table agrees
4. Gain **Broadcast Name** (party or personal — AI helps mint it)

## Sheet checklist

- Name / Broadcast Name  
- Stats  
- HP / Armor / Conditions  
- Inventory (10 slots) + Credits  
- Abilities  
- Achievement IDs earned  
- Spine flags (Odd Coin, Benefactor, etc.)
