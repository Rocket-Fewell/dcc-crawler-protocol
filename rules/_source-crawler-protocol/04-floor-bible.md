## 1. Intro — Purpose for the AI DM

This Bible is the **campaign spine**. Use it to:

1. Know what each floor *feels* like and what it unlocks before you write a playable `floors/floor-XX.md`.
2. **Plant seeds** early (objects, rumors, NPCs, system glitches) so later floors feel earned.
3. **Fire payoffs** when the party reaches the listed floor — never spoil early unless the seed is designed to surface partially.
4. Award **achievements** that feed soft unlocks (loot tags, shop access, race/class options) without replacing Core Rules math.

### How to use seeds

- Every seed has an ID like `SEED-ODDCOIN`.
- When you plant it, log in session state: `PLANTED | floor | what players saw`.
- When it pays off, mark `FIRED → Floor N` (never delete the row).
- Partial reveals are fine (signal gets clearer). Full identity / true power waits for the payoff floor.

### How to use achievements

- Announce with System / UI voice when earned.
- Rarity: **Common** / **Rare** / **Legendary** (see §5).
- Achievements may unlock shop tabs, cosmetic titles, one-shot loot rolls, or eligibility for a later floor rule — they do **not** auto-win fights.

### Floor 1 — The Orientation Pit

**Pitch:** A meat-grinder tutorial that teaches the System while pretending to be fair.

**Theme / vibe:** Concrete corridors, vending-machine loot, cheerful UI over corpses. Dark comedy; keep rules few.

**Special floor rules**
- Timer is generous compared to later floors; stairwells are many but contested.
- First death of a *named* NPC near the party triggers a System explainer popup (teach permanence).
- No race/class selection yet — everyone is **Baseline Crawler**.
- System voice is helpful-aggressive; show flavor is rare.

**Unlocks**
- Core crawler sheet (HP, basic stats — see Core Rules).
- Junk melee/ranged, scrap armor, med patches.
- Inventory + achievement toast UI.

**Seeds to PLANT**
| ID | What players see | Payoff floor(s) |
|----|------------------|-----------------|
| `SEED-ODDCOIN` | Dull stamped coin in a loot crate; System calls it *Vendor Oddity (Unappraised)*. | 3 (vendor), 6 (side path) |
| `SEED-BENEFACTOR` | Garbled private message mid-combat: `…HOLD… NOT YET…` with a broken crest. | 3 (clearer), 6 (choice), 12 (identity), 18 (endgame) |

**Payoffs that FIRE**
- None (campaign start).

**Achievement ideas**
- **Tutorial Complete** (Common) — Reach any Floor 1 stairwell alive.
- **Read the Manual** (Common) — Open the System help overlay once.
- **First Blood, Second Thoughts** (Common) — Score a killing blow.
- **Not Today** (Rare) — Survive a fight at ≤2 HP.
- **Witness Protocol** (Rare) — Be present when another crawler (PC/NPC) dies permanently.
- **Coin Collector** (Common) — Pick up `SEED-ODDCOIN` (hidden toast: *Oddity logged*).

**AI DM notes**
- Emphasize: UI literacy, scarcity of healing, that the show is watching.
- Do **not** explain the Benefactor or coin. Do **not** preview races/hunters/gods.

### Floor 2 — Soft Open

**Pitch:** The dungeon stops holding your hand; districts, dens, and “safe” rooms with teeth.

**Theme / vibe:** Rec-room aesthetics over killboxes; first recurring NPCs; traps that teach attention.

**Special floor rules**
- **Saferooms** exist but charge a toll (time, fame, or item).
- Trap density rises; failed Perception creates *noise* that pulls mobs.
- Companion / pet slots open if Core Rules allow.
- Optional mini-boss per district; not required for stairwell.

**Unlocks**
- Basic crafting bench (combine junk).
- Named district vendors (limited stock).
- Companion slot (1).

**Seeds to PLANT**
| ID | What players see | Payoff floor(s) |
|----|------------------|-----------------|
| `SEED-STATICSIGIL` | Chalky static mark behind a vending unit; flickers when touched. | 5 (bubble gate) |
| `SEED-GUIDECONTRACT` | Cheerful NPC guide offers a “free route map” with unread fine print. | 4 (clause bites), 9 (debt call) |

**Payoffs that FIRE**
- None required; optional echo of Benefactor static if party investigates radios.

**Achievement ideas**
- **Soft Open Survivor** (Common) — Clear Floor 2 objective.
- **Toll Paid** (Common) — Use a saferoom.
- **Fine Print** (Rare) — Actually read (or insist the AI read) the guide’s contract aloud.
- **Trap Artist** (Rare) — Disarm or intentionally trigger-and-kite 3 traps.
- **District Darling** (Rare) — Max reputation with one vendor district.
- **Spare Room** (Legendary) — Escape a mini-boss without killing it (bribe, lure, seal).

**AI DM notes**
- Emphasize: information has a price; NPCs have agendas.
- Do **not** resolve the guide’s true employer. Do **not** open bubble lore yet.

### Floor 3 — Highstreet Sprawl

**Pitch:** A neon over-city where race and class choices lock in under live ratings.

**Theme / vibe:** Crowds, quest boards, municipal law, first real *identity* moment. (Public vibe: Over City–like.)

**Special floor rules**
- **Race + class selection** window opens on entry (timer); late picks get worse options.
- City law: assault in marked zones triggers Desperado status (bounties).
- Quest boards refresh; some quests are sponsor bait.
- Stairwells gated by contribution score *or* a hard side-objective.

**Unlocks**
- Full race list (tier 1) and class list (tier 1) — see Character Creation.
- City shops (armor fashion, skill primers).
- Reputation tracks with 2–3 street factions.

**Seeds to PLANT**
| ID | What players see | Payoff floor(s) |
|----|------------------|-----------------|
| `SEED-SPONSORBAIT` | Flashy offer: free legendary-looking cloak for “one future favor.” | 6 (favor called), 10 (strings) |

**Payoffs that FIRE**
- `SEED-ODDCOIN` → Appraiser NPC recognizes mint; offers trade *or* rumor of a “hunter-safe alley” (full alley waits for F6).
- `SEED-BENEFACTOR` → Message clarifies: *You are being watched by more than the audience.* Crest half-renders.

**Achievement ideas**
- **Identity Locked** (Common) — Finalize race + class.
- **Law-Abiding Murderer** (Common) — Kill only in unmarked combat zones.
- **Desperado** (Rare) — Earn and clear a city bounty.
- **Board Sweeper** (Rare) — Complete 5 board quests before descent.
- **Oddity Appraised** (Rare) — Show `SEED-ODDCOIN` to the right vendor.
- **Favor Unsigned** (Legendary) — Refuse `SEED-SPONSORBAIT` and still clear the floor.

**AI DM notes**
- Emphasize: choice permanence, social danger, comedy of bureaucracy.
- Do **not** reveal hunter invasion (F6) or warlord draft (F9).

### Floor 4 — The Knotline

**Pitch:** The map is a transit knot; wrong line = death, right relay = salvation.

**Theme / vibe:** Trains, one-way rails, yard politics, infrastructure as puzzle. (Public vibe: Iron Tangle–like.)

**Special floor rules**
- Movement between hubs requires **line tickets** or hijacked cars.
- Some lines are one-way; System will not warn until boarding.
- Party can split across cars — recommend shared timers.
- Sabotaging a line helps *and* strands other crawlers (moral weight).

**Unlocks**
- Transit Key item type.
- Relay / signaler gear (party coordination).
- Saboteur toolkit (limited charges).

**Seeds to PLANT**
| ID | What players see | Payoff floor(s) |
|----|------------------|-----------------|
| `SEED-RAILKEY` | Brass key stamped with a route that “doesn’t exist on this floor.” | 7 (shortcut), 10 (garage override) |

**Payoffs that FIRE**
- `SEED-GUIDECONTRACT` → Fine print: guide’s employer owns a Knotline franchise; map was a recruitment funnel. Guide may return as yard boss or debtor.

**Achievement ideas**
- **Right Line** (Common) — Reach stairwell via any legal route.
- **Conductor** (Rare) — Guide another crawler party to a hub (roleplay or shared objective).
- **Ghost Schedule** (Rare) — Board a hidden/off-timetable car.
- **Yard Heist** (Rare) — Steal a fresh car from a secured yard.
- **Clause Cleared** (Legendary) — Nullify or renegotiate `SEED-GUIDECONTRACT` in public.
- **No One Left on the Platform** (Legendary) — Exit with every living allied NPC you accepted responsibility for.

**AI DM notes**
- Emphasize: logistics, trust, map literacy.
- Do **not** explain why the brass key’s route “will matter when speed is law.”

### Floor 5 — Bubble Farms

**Pitch:** Pocket biomes in fragile bubbles; selfish clears doom neighbors.

**Theme / vibe:** Greenhouse sci-fi + fairy-tale ecology; cooperation under ratings. (Public vibe: Bubbles–like.)

**Special floor rules**
- Each bubble has a **climate rule** (drown, burn, silence, etc.).
- Collapsing a bubble without evacuating NPCs tanks global score / spawns revenge mobs.
- Cross-bubble trades (air, heat, seeds) are optimal play.
- Rumors of “feral divinity” appear as environmental omens only.

**Unlocks**
- Biome kits (resist tags).
- Temporary multi-party alliance UI.
- Rare divine-adjacent trinkets (flavor; power later).

**Seeds to PLANT**
| ID | What players see | Payoff floor(s) |
|----|------------------|-----------------|
| `SEED-BUBBLECORE` | Fist-sized living core that hums in major thirds; System: *Sample — Do Not Ingest.* | 8 (echo fuel), 15 (infernal reaction) |

**Payoffs that FIRE**
- `SEED-STATICSIGIL` → Matching mark appears on a sealed bubble membrane; touching opens a **side bubble** with unique loot and a prophetic mural (no spoilers — abstract art only).

**Achievement ideas**
- **Bubble Hopper** (Common) — Clear 3 distinct biomes.
- **Climate Control** (Rare) — Stabilize a collapsing bubble.
- **Farmers’ Market** (Rare) — Complete a cross-bubble resource trade.
- **No Collapse** (Legendary) — Exit without any bubble in your sector rupturing.
- **Core Sample** (Rare) — Extract `SEED-BUBBLECORE` intact.
- **Guest of the Greenhouse** (Legendary) — Earn sanctuary from a biome’s ruling NPC without combat.

**AI DM notes**
- Emphasize: interdependence, spectacle of beautiful danger.
- Do **not** name the Cage entity. Do **not** confirm gods are real yet — only omens.

### Floor 6 — Open Season

**Pitch:** Licensed hunters from outside enter; you are the content.

**Theme / vibe:** Trophy culture, sponsorship betrayal, counter-hunt catharsis. (Public vibe: Hunting Grounds–like.)

**Special floor rules**
- **Hunters** are higher-level outsiders with extract rights; killing one is huge.
- Sponsor favors can be called in (including `SEED-SPONSORBAIT`).
- Safe extract zones for hunters; crawlers can sabotage beacons.
- Night/day cycle changes hunter loadouts.

**Unlocks**
- Hunter-derived weapons and trophies.
- Counter-hunt gadgets (beacons, scent masks).
- Mid-tier sponsor shop (dangerous).

**Seeds to PLANT**
| ID | What players see | Payoff floor(s) |
|----|------------------|-----------------|
| `SEED-HUNTERBADGE` | Bloodied elite badge; System offers *Claim Kill Credit?* | 9 (war credential), 11 (named-opponent rights) |

**Payoffs that FIRE**
- `SEED-ODDCOIN` → Full payoff: coin opens **hunter-blind alley** / black-market gate with unique escape or ambush setup.
- `SEED-BENEFACTOR` → Clearer offer: protection *or* information; choosing binds a later debt (track in session state). Identity still masked.
- `SEED-SPONSORBAIT` → Favor called: wear the cloak on camera during a hunt (buff + vulnerability) *or* refuse and lose sponsor tier.

**Achievement ideas**
- **Open Season** (Common) — Survive first hunter encounter.
- **Trophy Reversal** (Rare) — Kill a hunter.
- **Badge of the Fallen** (Rare) — Claim `SEED-HUNTERBADGE`.
- **Beacon Blackout** (Rare) — Sabotage a hunter extract.
- **Favor Called** (Common) — Resolve `SEED-SPONSORBAIT` either way.
- **Unbought** (Legendary) — Refuse Benefactor *and* sponsor leverage on this floor and still descend.

**AI DM notes**
- Emphasize: power fantasy with cost; audience loves hunter deaths.
- Do **not** preview Mandate Wars command structure. Benefactor face remains hidden.

### Floor 7 — Greenlight Gauntlet

**Pitch:** A timed maze/race where the smart route beats the strong build.

**Theme / vibe:** Starting-gun comedy, branching tubes, cheaters celebrated if funny. (Public vibe: Great Race–like.)

**Special floor rules**
- Floor may be **short-cleared** if party finds a legal exploit documented by System as *Unintended but Allowed*.
- Checkpoints stamp time; last waves get harder spawns.
- Mounts / simple vehicles available for rent or theft.
- Killing rival crawlers is optional and ratings-positive (table can soft-ban PvP).

**Unlocks**
- Mounts / light vehicles.
- Speed-oriented gear enchant tags.
- Shortcut lore entries (feed F10/F17).

**Seeds to PLANT**
| ID | What players see | Payoff floor(s) |
|----|------------------|-----------------|
| `SEED-SHORTCUTMAP` | Torn schematic labeled *BACKSTAGE ACCESS — DO NOT DISTRIBUTE*. | 10 (pit lane), 17 (catwalk) |

**Payoffs that FIRE**
- `SEED-RAILKEY` → Fits a sealed maintenance gate; reveals a **greenlit illegal-legal** shortcut (System laughs in chat).

**Achievement ideas**
- **Greenlit** (Common) — Hit the exit before hard timer.
- **Personal Best** (Rare) — Beat the party’s first checkpoint time by 25%+.
- **Unintended Allowed** (Legendary) — Discover and use a System-acknowledged exploit route.
- **Pacifist Heat** (Rare) — Clear without downing rival crawlers.
- **Key Fit** (Rare) — Use `SEED-RAILKEY` successfully.
- **Map Thief** (Rare) — Acquire `SEED-SHORTCUTMAP`.

**AI DM notes**
- Emphasize: clever > grind; celebrate player ingenuity.
- Do **not** explain what “backstage” physically is (save for F17).

## 5. Achievement design notes

### Rarity tiers

| Tier | Frequency | Typical reward |
|------|-----------|----------------|
| **Common** | Most clears earn 2–4 | Title, small loot roll, scrip crumb |
| **Rare** | Skill/choice gated | Shop tab, unique cosmetic, solid loot |
| **Legendary** | Campaign-defining | Soft unlock (route, patron, ending eligibility), prestige title |

### How achievements feed unlocks

1. **Eligibility gates** — e.g. Legendary `Unintended Allowed` (F7) unlocks a F10 illegal pit without needing the key.
2. **Loot tags** — Rare achievements add a tag the shop respects (`Hunter-Slayer`, `Vowkeeper`).
3. **Scrip** — From F14 on, achievements mint Continuity Scrip.
4. **Never** replace a missed skill check with an achievement autopass in the same scene.

### Naming flavor

- Prefer game-show / System toast energy: short, punchy, slightly cruel.
- Original names only — do not clone achievement titles from the novels.

### AI DM hygiene

- Toast immediately when earned; log in session state.
- If two PCs qualify, both get it (unless explicitly solo).
- Retconning an achievement away requires table consent.
