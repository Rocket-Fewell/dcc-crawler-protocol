# Decision 015: Legendary Story Boxes on Floor 1
Owner: Borent Corp Systems Architect | Status: final | Version: 1.3 | Updated: 2026-10-04
Summary: One-time-deed Legendary boxes are allowed on Floors 1-2 as a narrow exception to core §4.1 (rules/40 §2.8). The tooling makes them hard to misuse. v1.1: Caleb's answers (decision 018) applied: tradeable, saferoom-only opening, cap per floor, rota is a guideline.

- Approved by: Caleb, 2026-10-04 (passed on by the parent agent). Quadruped Box covers any quadruped companion, not just cats.
- **Hand-pick only.** `loot draw` refuses Legendary cards; random draws never contain them. The only path is `state.py loot story-box`.
- **A recorded deed.** `--deed "text"` is required; who, when, floor, witness and GM note are stored in `story-box-ledger.jsonl` (per session). The registry refuses to pay the same deed twice (key = the card's own deed, or `--deed-id`).
- **Cap.** One Story Box per table per floor (the whole floor, not per play night; each campaign instance, alpha or beta, keeps its own ledger and count). This is the only hard limit on awards. `--override-cap "reason"` exceeds it and logs the reason. Cards of one box (e.g. Enhanced Pet Biscuit + Pet Biscuit Crate) go in one command (`--pick A,B`), count once, and record a same-box reason.
- **Tradeable, never auto-credits (v1.1).** Story Box items are NOT bound: once opened they are ordinary loot (lootable from corpses, transferable, sellable). Cards carry `bound: false`. `story_value` is logged separately as provenance only; it is never a price, a buyback base or credits; `economy_value` is 0 at award; a Legendary card that grants credits is refused. The System buys an item back for a fixed `sale_value` by power rung (100 / 250 / 500 at Floor-1 scale, times the sale floor's credit multiplier; rules/45 §4.6). Sales between Crawlers are free-form credit transfers with `story_value` kept as provenance. `loot totals` shows both columns; the Accountant's 1,500-per-floor inflation flag excludes the award's story value but counts sale proceeds, and flags them without blocking.
- **Saferoom only (v1.1).** Like every loot box a Story Box opens only in a safe room (core §4.4, unchanged). The deed is recorded and announced at award time; the box is held unopened until the next saferoom.
- **Death (v1.1).** Death is nearly game over. Opened Story Box items drop with the corpse cache and can be looted; no repossession and no reissue after revival. An unopened box is reclaimed like any unopened box (core §6.2). The deed stays closed (v1.3: the reclaimed box frees its cap slot so another Crawler can be awarded one; see decision 020 v1.2). For an opened item the cap slot stays used until the dead Crawler is deleted.
- **Spotlight guideline (v1.1).** "Try to give every living Crawler a first Story Box before anyone gets a second" is GM guidance, not a hard rule (`limits.story_box_rota` warns only).
- **Warnings, not blocks.** Missing `power_note:`, empty effect text, a deck HOLD note (Lore removes it), no witness or GM note.
- **Switch.** `limits.legendary_enabled` (default true for new sessions; set true on alpha). Setting it false refuses all Story Boxes.
- Files: tools/loot.py, tools/state.py, tools/ledgers.py; tests/test_story_box.py. GM guide: gm-notes/31-story-box-how-to.md.
- **Tooling (v1.2).** Two steps: `loot story-box FLOOR ZONE ...` (award: deed recorded, box queued unopened, box ledger `earned`) and `loot story-box --open --crawler X --safe-room`. Safe room = `--safe-room` or `state.py scene safe-room on`; it applies to every loot box (`box open`, `loot draw`). `sell` (System buyback = the card's `sale_value` x the sale floor's multiplier, default 500, never `story_value`) and `transfer` (free-form `--price`) are ordinary credit-ledger transactions carrying `provenance.story_value`; Story Box sales are flagged in `loot totals` and `ledger verify`, never blocked, and sale proceeds count toward the 1,500-per-floor flag. Repossess/restore was removed (items are lootable). `story_box_rota` accepts only `warn`.
- **Pet-Crawler (v1.2).** An Enhanced Pet Biscuit fed to a pet makes it its own Crawler (`kind: pet-crawler`), played by the player who made it, no extra slot, once per pet, consumes the biscuit, own sheet channel. The pet-Crawler can't be traded, sold or looted; an unused biscuit is an ordinary item. Tests: tests/test_safe_room_sales.py.
