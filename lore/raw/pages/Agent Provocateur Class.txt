Agent Provocateur is one of three Compensated Anarchist Class Upgrades available during  6th floor class selection.  

==AI Description==
The mysterious Agent Provocateur prides himself in being invisible. This class specialty focuses on being the ultimate saboteur. These wily troublemakers emphasize less on individual traps and fighting in the street and instead focus on mass-casualty bombs and bomb-making.

An Agent Provocateur receives the following benefits:
*An additional +1 to intelligence upon level-up
*+1 skill level to a Sapper's Table.
*+2 to Explosives Handling Skill
*Access to the advanced Bomb Maker's Workshop.
*Faster explosives training.

==Story==
Although Mordecai advises Carl to choose the melee-focused Revolutionary Class upgrade, Carl ultimately selects the bomb-focused Agent Provocateur class.  The third option was the trap-based Guerilla Class specialization.

As Carl is the only crawler who chose the Compensated Anarchist class on the Third Floor, no other crawlers would have the option to choose this class on the Sixth Floor. 

==Trivia==

* An "agent provocateur" is someone who (a) commits illegal acts, (b) takes action to convince others to commit illegal acts, and/or (c) falsely implicates someone else for an illegal act with  the intention of ruining the person's reputation and/or instigating legal action against that person.  Agent provocateurs typically target groups.
* Agent Provocateur also happens to be an international luxury lingerie and boudoir store.
