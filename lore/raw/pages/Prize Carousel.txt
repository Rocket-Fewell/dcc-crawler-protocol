The Prize Carousel is a time-restricted Dungeon minigame hosted by Chaco.  Crawlers can receive the ability to "play" if their fans select it as a Fan Box reward, but it is not particularly popular and only happens a few times each season. [3|7]

== Description ==
Heralded by colored lights and cheesy 1970s game show music, the Prize Carousel is a spinning, twinkling carousel that appears in the crawler's safe room after the Fan Box is opened.  It has nine curtained-off sections containing nine prizes.

The crawler has ten minutes to select a prize, but is not able to scan the items or view tooltip descriptions of the items. [3|7]

===Book 3===
